# 42 Piscine

This repository is a collection of the exercises and projects I completed during the Piscine at 42 Heilbronn.

The Piscine is an intensive four-week introduction to programming, mainly focused on C.

The Piscine covers the foundations of C programming, from functions and loops to pointers, strings, recursion, and algorithms, alongside Shell, terminal navigation, Git, and debugging.

## What I Completed

| Module  | Main topics                                        |
| ------- | -------------------------------------------------- |
| C00     | Basic functions, loops, characters, and output     |
| C01     | Pointers, arrays, string length, and sorting       |
| C02     | String copying and character validation            |
| C03     | String comparison, concatenation, and searching    |
| C04     | Number output, string conversion, and number bases |
| C05     | Recursion, factorials, powers, and Fibonacci       |
| C06     | Command-line arguments                             |
| Rush 01 | Skyscraper puzzle group project                    |

Some exercises contain individual functions rather than complete programs, so they may require a separate `main.c` file for testing.

## Note

This repository is a record of my learning and progress during the Piscine. If you are currently doing the Piscine, I recommend trying to solve the exercises yourself before looking at other solutions.
