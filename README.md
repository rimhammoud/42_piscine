# 42 Piscine

This repository contains the exercises and projects I completed during the Piscine at 42 Heilbronn.

## About the Piscine

The Piscine is an intensive four-week introduction to programming and the C language. Instead of traditional classes, students learn through exercises, research, peer evaluations, exams, and group projects.

## What I Learned

During the Piscine, I learned:

- C fundamentals
- Functions, loops, and conditions
- Pointers, arrays, and strings
- Recursion and basic algorithms
- Command-line arguments
- Git and terminal commands
- Debugging and testing
- Independent learning and teamwork
